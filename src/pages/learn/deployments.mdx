# Deployments

:::note
This page contains information that is only relevant to developers who would
like to interact with the contract manually. Most libraries will handle this
for you.
:::

ENS is multichain (read more [here](/web/multichain)) and can be used in any application.
In addition to being able to query many address formats and record types, data can be stored [practically anywhere](/learn/ccip-read).
However, resolution needs to start somewhere, so the entrypoint for resolution is Ethereum Mainnet, alongside the most popular testnets.

## Deployments

Below you will find an abbreviated list of our latest contract deployments. The source of truth for ENS contract deployments is the [ensdomains/ens-contracts](https://github.com/ensdomains/ens-contracts/tree/staging/deployments) repository.

### Mainnet

Interact with ENS on Ethereum Mainnet via [app.ens.domains](https://app.ens.domains).

### Sepolia (ENSv2 Beta)

:::warning
**ETHOnline 2026**: the table below lists the dedicated hackathon [ENSv2](/ensv2/overview) deployment, which is separate from the standard ENSv2 Beta deployment on Sepolia. Build your hackathon project against these addresses. Interact with this deployment via the hackathon [ENS App](https://hackathon-deployment-manager-app-v4.ens-cf.workers.dev/) and [ENS Explorer](https://hackathon-deployment-portal-app.ens-cf.workers.dev/), which serve it exclusively.
:::

For name resolution to use the hackathon deployment, the [Universal Resolver](/ensv2/universal-resolver-v2) address built into viem and ethers must be overwritten once in your code with the hackathon Universal Resolver (`UpgradableUniversalResolverProxy` in the table below):

:::code-group

```ts [Viem]
import { createPublicClient, http } from 'viem'
import { sepolia } from 'viem/chains'

// Sepolia with the hackathon Universal Resolver instead of the built-in one
const hackathonSepolia = {
  ...sepolia,
  contracts: {
    ...sepolia.contracts,
    ensUniversalResolver: {
      address: '0xd26f2040d083af1cd2962ba303f4bea0c4faf142',
    },
  },
} as const

const client = createPublicClient({
  chain: hackathonSepolia,
  transport: http(),
})

// getEnsAddress, getEnsName, getEnsText, ... now resolve
// against the hackathon deployment
```

```ts [Ethers (>= 6.17)]
import { JsonRpcProvider } from 'ethers'

// Sepolia network with the hackathon Universal Resolver
const network = {
  name: 'sepolia',
  chainId: 11155111,
  ensUniversalResolver: '0xd26f2040d083af1cd2962ba303f4bea0c4faf142', // hackathon Universal Resolver
}

const provider = new JsonRpcProvider(RPC_URL, network, {
  staticNetwork: true,
})

// provider.resolveName, provider.lookupAddress, ... now resolve
// against the hackathon deployment
```

:::
