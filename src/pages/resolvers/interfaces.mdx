# Resolver Interface Standards

This page is a collection of methods that a resolver MAY implement.

## ENSv2 Permissioned Resolver

The [Permissioned Resolver](/ensv2/permissioned-resolver) reads records through `resolve(bytes,bytes)` (ENSIP-10). The requested profile call, such as `text(bytes32,string)` or `addr(bytes32,uint256)`, is encoded inside that call. The resolver does not expose those legacy getters as direct methods or advertise their individual interface IDs.

Its record setters accept a DNS-encoded name rather than a namehash. The following interface IDs are supported by `supportsInterface`:

| Interface                            | ID           |
| ------------------------------------ | ------------ |
| ERC-165: `supportsInterface(bytes4)` | `0x01ffc9a7` |
| ENSIP-10: `resolve(bytes,bytes)`     | `0x9061b923` |
| ERC-7996: `supportsFeature(bytes4)`  | `0x582de3e7` |
| `setABI(bytes,uint256,bytes)`        | `0xd26f550e` |
| `setAddress(bytes,uint256,bytes)`    | `0xb4436dde` |
| `setContenthash(bytes,bytes)`        | `0xc5d7badd` |
| `setData(bytes,string,bytes)`        | `0xeb4b73bb` |
| `setInterface(bytes,bytes4,address)` | `0x9ce8c375` |
| `setName(bytes,string)`              | `0x0ce0112a` |
| `setText(bytes,string,string)`       | `0xc7279f88` |

For example, the v1 `setText(bytes32,string,string)` selector `0x10f13a8c` is not the ENSv2 text setter. An interface check also does not establish write permission. See [Interacting with a Resolver](/resolvers/interacting) for resolver discovery and version-specific writes.

For the complete interfaces, including record linking, multicall, access control, and upgrades, see [PermissionedResolver.sol](https://github.com/ensdomains/contracts-v2/blob/fce23470d9d9cd7cad3da02bb4b447119fdf4c42/contracts/src/resolver/PermissionedResolver.sol) and [AbstractRecordResolver.sol](https://github.com/ensdomains/contracts-v2/blob/fce23470d9d9cd7cad3da02bb4b447119fdf4c42/contracts/src/resolver/AbstractRecordResolver.sol).
